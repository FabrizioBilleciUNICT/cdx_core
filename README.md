CdxCore by Codedix - A Flutter core package providing essential utilities, services, and models for building scalable applications.

## Features

- 🎨 **Theme Management**: Comprehensive theme services and models
- 🔧 **Service Interfaces**: Abstract interfaces for app, event, media, and theme services
- ☁️ **Cloud Services**: CRUD service interfaces and cloud platform abstractions
- 📦 **Core Models**: Essential data models including base objects, filters, and form items
- 🛠️ **Utilities**: Date utilities, extensions, and timed event handlers (debounce, throttle)
- 💉 **Dependency Injection**: Built-in support with get_it

## Installation

Add `cdx_core` to your `pubspec.yaml`:

```yaml
dependencies:
  cdx_core: ^0.0.2
```

Then run:

```bash
flutter pub get
```

## Usage

Import the package:

```dart
import 'package:cdx_core/cdx_core.dart';
```
